# Python Mini Projects (OOP & Problem Solving)

## Overview

This repository contains two Python projects developed to demonstrate **Object-Oriented Programming (OOP)** and **problem-solving skills**.

---

## Projects Included

### 1. Library Management System (OOP)

A simple system to manage books and users using OOP concepts.

#### Features

* Add and manage books
* Issue and return books
* Search books by title
* Track availability

#### OOP Concepts Used

* Encapsulation
* Inheritance (Student, Faculty from User)
* Polymorphism (method overriding)
* Aggregation (Library manages books)

#### Run

```
python LibraryManagement.py
```

---

### 2. LPP Solver (2 Variables)

A program to solve Linear Programming Problems in two Variables 
####  Features

* Handles constraints for 2 variables
* Finds feasible region
* Calculates optimal solution (max/min)

#### Run

```
python LppIn2Variables.py
```
